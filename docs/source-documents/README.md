# Supplied project documents

These files are reference material supplied by the team; they are not evidence that features have been implemented.

- `security-notes.txt` — initial ideas for identity, protected terms, reviews, late returns, photos and account suspension. See [the build plan](../build-plan.md) for safeguards and open decisions.
- `mid-semester-notice-nov-2026.pdf` — the 3 November 2026 assessment notice. The guide confirms scheduling and any updates.
- `review-preparation-guide.pdf` — a suggested **mid-semester Review 1** preparation plan (despite its original filename, `review-2-steps.pdf`); its schedule and suggestions are not additional notice requirements. Pages 7–8 list eight possible literature starting points that need independent verification.
- The supplied `Borrow Instead of Buy Edi project-2- finalisation.pdf` is the FF-180 registration, synopsis and blank review forms. It contains personal phone numbers, emails and student identifiers, so the original is intentionally not stored in the repository. Keep it privately and consult the guide for the official form. Its non-sensitive project information is summarized in the [source summary](../source-summary.md).

Do not add personal contact details, student identifiers, signed forms or geotagged review photos to the repository without an agreed privacy and access policy.
